# COMPONENT CATALOG — جرد مكونات WERA PRO HD (G2)

> **الوثيقة:** WERA-CC-001 · **الإصدار:** 1.0 (G2 — للاعتماد) · **التاريخ:** 2026-11-01
> **المرجع الناظم:** GFM-CSharp 2.4.1 §7.1/§7.2 (Tokens وحالات المكونات) و§7.2.1 (معيار الجدول) و§7.3 (التنقل العلوي)
> **القاعدة:** لكل مكون: Tokens مركزية · حالات إلزامية · قواعد RTL · قاعدة وصول. لا قيمة hardcoded إن كان لها Token.

## اصطلاح الحالات
`DEF` افتراضي · `HOV` مرور · `FOC` تركيز (حلقة 2px `focusRing`) · `PRS` ضغط · `SEL` مختار · `DIS` معطل (Opacity 0.45 + مؤشر «غير متاح» نصي عند الحاجة) · `LOAD` تحميل (skeleton/spinner) · `EMPTY` فارغ · `SUC/WAR/ERR` حالات النتيجة — **دائماً لون + نص + أيقونة، لا لون وحده (§6)**.

---

## 1. الأساسيات

### C-01 Button
- متغيرات: `Primary` (خلفية `action.primary`، نص أبيض) · `Secondary` (سطح أبيض + حد) · `Subtle` (بلا حد) · `Danger` (حد/نص `status.danger`؛ الخلفية الحمراء للإجراء المدمّر المؤكد فقط) · `Gold` (تمييز محدود جداً — شارة قيمة مالية قابلة للنقر).
- ارتفاع: إداري 42 · أساسي/لمسي 50 · إجراء جدول 34. نصف قطر 8. أيقونة 20 + تسمية.
- حالات: كاملة (DEF/HOV/FOC/PRS/DIS/LOAD — زر الدفع يعرض «جارٍ الترحيل…» مع تعطيل، لا يختفي).
- RTL: الأيقونة بداية السطر (يمين في RTL)؛ Chevrons تنعكس في LTR.

### C-02 TextBox / SearchBox / BarcodeField
- ارتفاع 42، نصف قطر 8، حد `border.default` يتحول `action.primary` عند FOC.
- `BarcodeField`: خط mono، اتجاه LTR داخلي، لصق/مسح فوري، صافي 1px Teal عند «في انتظار مسح» — النموذج الحي في POS.
- بحث الجداول: Debounce 300ms + إلغاء الطلب السابق؛ زر مسح (×) دائم الظهور عند وجود نص.

### C-03 NumberBox / AmountBox
- أرقام tabular، محاذاة نهاية، الوحدة suffix منفصل («ج.م» / «كجم» / «وحدة») لا داخل الرقم.
- `AmountBox` (وزن/مبلغ مستهدف): عرض القيمة الدقيقة والمعروضة معاً عند اختلافهما (D-07): «الدقيق 348g ← المعروض 350g (خطوة 5g)».

### C-04 ComboBox / DatePicker / ToggleSwitch / CheckBox / RadioButtons
- ارتفاع 42 موحد؛ القوائم تدعم الأسهم/Enter/Escape/النقر خارجها؛ DatePicker بأسماء أشهر عربية.

## 2. الجدول المعياري — WERA Premium Data Grid (§7.2.1)

### C-10 WeraDataGrid
- **بنية:** قبل اختيار مكتبة DataGrid لـWinUI 3 يُفحص توافقها مع .NET 10 وWindows App SDK والترخيص والصيانة والأداء؛ لا مكتبة مهجورة — وإلا يُبنى مكوّن مخصص بـItemsRepeater/ListView (قرار يوثق في G3 مع ADR).
- **الترويسة:** ثابتة (sticky) بخلفية `surface.tableHeadBg`، خط 13/600، فرز بمؤشر مرئي ▲▼، تغيير عرض/ترتيب/إخفاء أعمدة من Column Chooser، تثبيت أعمدة حرجة عند الدعم.
- **الصفوف:** 49px (Compact 40)، حدود أفقية 1px فقط، بلا Zebra صارخ، Hover هادئ `surface.subtle`، `SEL` بسطح `action.primary.soft` + علامة ✓ + إطار 1px Teal.
- **أنواع الخلايا:** Text · Secondary · Numeric · Currency (منزلتان + ج.م) · Quantity/Weight (وحدة مستقلة) · Date/Time · StatusBadge · Thumbnail 36 · SKU/Barcode (LTR mono) · RowActions (الأكثر استخداماً ظاهر + «المزيد»).
- **Toolbar إلزامي بالترتيب:** العنوان+العدد · بحث · فلاتر نشطة (chips قابلة للإزالة) · فلاتر متقدمة · فرز · تحديث · Column Chooser · Pagination · تصدير (بصلاحية) · إجراء رئيسي واحد. **لا صف أزرار مزدحم.**
- **السلوك:** server-side بالكامل للبيانات الكبيرة، Virtualization، الحفاظ على الصف المحدد عند التحديث، skeleton عند LOAD، `EMPTY` يشرح السبب + زر «مسح الفلاتر»، `ERR` برسالة + Retry — **صفحة فشل الاتصال لا تتحول أبداً إلى جدول فارغ يوحي بعدم وجود بيانات.**
- **اختبار القبول:** بحث/فلاتر/فرز/تقسيم/تصدير/صلاحيات تعمل فعلياً؛ لا قص أو تداخل أعمدة في المقاسات المعتمدة؛ 100 و10,000 سجل؛ قياس ذاكرة وتمرير (في G4+ على بيئة Windows).

### C-11 FilterChip
- شارة فلتر نشط: خلفية `action.primary.soft` + حد + × إزالة؛ يعرض القيمة المختارة نصاً («الفئة: ألبان»).

### C-12 PaginationBar
- «عرض 1–50 من 12,480» + أزرار صفحة/سابق/التالي + حجم صفحة (50/100/250) — أرقام LTR.

### C-13 ColumnChooserFlyout
- قائمة أعمدة بعيون ✓، سحب ترتيب، «استعادة الافتراضي».

## 3. البنية الصفحية

### C-20 TopNavBar (§7.3 — لا Sidebar)
- خلفية `brand.navy`، ارتفاع 56: الشعار · الفرع/المحطة · 10 مجموعات (التشغيل/المبيعات/الكتالوج/المخزون/المشتريات/الأطراف/المالية/التقارير/الأجهزة/الإدارة والأمان) · Ctrl+K · حالة اتصال حقيقية (متصل/انقطع — لا تظهر «متصل» زوراً) · إشعارات · المستخدم/الدور + اللغة + الثيم.
- عند الضيق: مجموعة «المزيد» — لا قص عناصر. المحظور: الوصول لصفحة بلا صلاحية عبر أمر/اختصار.

### C-21 PageHeader
- عنوان 26/700 + وصف ثانوي 13 + الإجراء الرئيسي يمين/يسار حسب الاتجاه + Breadcrumb عند العمق >1.

### C-22 KpiCard
- تسمية 13 `text.secondary` · قيمة 26/700 `brand.navy` (المالية بشارة ذهبية رفيعة) · دلتا ▲▼ بنص لا لون فقط · مصدر البيانات وتوقيته caption — «لا يُعرض مؤشر بلا مصدر».

### C-23 Card / SectionCard
- سطح أبيض، حد 1px، نصف قطر 12–16، بلا ظل (ظل level2 للطافي فقط).

### C-24 Tabs / SegmentedControl
- عنوان القسم النشط بخط سفلي 2px Teal؛ لا تبويبات متداخلة الأعماق.

### C-25 MasterDetailPane
- قائمة يسار/يمين + تفاصيل؛ للعملاء/الموردين/الورديات؛ يوزع 40/60 في 1920 و30/70 في 1366.

### C-26 Wizard / StepFlow
- خطوات مرقمة بعناوين (معالج إعداد طابعة/ميزان، جرد، استيراد) — الحالة: منجزة ✓/حالية/قادمة + إلغاء موثق.

## 4. التغذية الراجعة والحالات

### C-30 StatusBadge
- `مرحّل/SUC` `بانتظار اعتماد/WAR` `مرفوض/ERR` `مسودة/INFO` `معطل/DIS` — دائماً نقطة/أيقونة + نص.

### C-31 InfoBar / Toast
- أعلى الصفحة 4 أنواع (SUC/WAR/ERR/INFO) + إجراء واحد + إغلاق؛ لا تكديس Toasts — آخر 3 فقط.

### C-32 ContentDialog
- عنوان + جسم + إجراءات (الأساسي Teal يميناً)؛ العمليات الخطرة تتطلب كتابة كلمة تأكيد («ترحيل»)؛ FOC محبوس داخل الحوار.

### C-33 CommandPalette (Ctrl+K)
- بحث موحد بالصفحات والإجراءات وpage_id؛ طافي level2؛ أسهم + Enter + Escape؛ النتائج مقيدة بصلاحية المستخدم.

### C-34 EmptyState
- أيقونة 48 + عنوان + شرح السبب + إجراء («مسح الفلاتر» / «إضافة أول منتج») — لا يُختصر إلى «لا بيانات».

### C-35 LoadingSkeleton
- صفوف/بطاقات رمادية `surface.subtle` بومضة هادئة 1.2s — لا spinners كبيرة في وسط الجداول.

### C-36 ErrorState / ConnectionLost
- رسالة + Retry + تفاصيل تقنية قابلة للفتح + Correlation ID؛ تظهر كموقع مختلف عن EMPTY — لا التباس.

## 5. مكونات POS الخاصة

### C-40 PosShell
- نافذة مستقلة بلا قائمة إدارية؛ خلفية `surface.background`؛ شريط حالة سفلي (الوردية/المحطة/الاتصال/الوقت).

### C-41 CartGrid (جدول السلة المركزي)
- أعمدة: ✓ حذف · الصنف+SKU · الكمية/الوزن (قابلة للتحرير بمونو) · سعر الوحدة · الخصم · الإجمالي (Currency) — الصف النشط أثناء التحرير بإطار Teal؛ صف 46px؛ لا ظل.

### C-42 TotalsPanel
- «الإجمالي» بحجم 32/700 بشارة ذهبية رفيعة + «الضريبة المضمّنة 14%» سطر ثانوي (D-01) + الخصم + المستحق؛ ارتفاع الزر الأساسي 50.

### C-43 WeightPanel (نافذة الوزن)
- 6 طرق الإدخال بمفاتيح تبويب واضحة: قارئ الميزان · إدخال يدوي (دقة 1g) · مبلغ مستهدف (→ وزن لأقرب خطوة 5g) · أزرار وزن سريع (تخفي نفسها إن خالفت خطوتها دقة الصنف) · باركود ملصق الوزن · عبوة موزونة.
- يعرض: القيمة الدقيقة والمعروضة معاً + السعر المرجعي/كجم + الحساب الحي (200 ج.م/كجم × 350 جم = 70.00 ج.م).

### C-44 PaymentWindow
- المستحق كبير أعلى · وسائل الدفع (نقد/بطاقة/مختلط/آجل) · لوحة أرقام لمسية (أهداف ≥48) · Split واضح · الباقي بارز؛ البطاقة `BLOCKED_EXTERNAL_DEPENDENCY` تظهر معطلة بسببها لا مختفية (B-02).

### C-45 QuickPickRail
- شريط أصناف سريعة (أكثر مبيعاً/مفضل) بصور 40 — يخفى دون 1280px.

### C-46 FunctionKeysBar
- F1..F12 مخططة: F1 بحث · F2 وزن · F4 دفع · F8 تعليق · F12 مرتجع — ثابتة لا تتغير بين الإصدارات.

## 6. قواعد وصول عامة (تُختبر في كل بوابة)
- حلقة تركيز مرئية دائماً؛ Tab/Shift+Tab منطقي في RTL (يميناً أولاً).
- اختصارات لا تُشغّل إجراءاً خارج صلاحية المستخدم — الزر معطل مع Tooltip السبب.
- النصوص لا تُقص: التفاف أو Ellipsis + Tooltip.
- Contrast: نص أساسي ≥ 4.5:1، قيم مالية ≥ 3:1 على خلفياتها (يُفحص آلياً في G11).
