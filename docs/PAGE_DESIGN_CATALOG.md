> **المرجع الناظم:** GFM-CSharp 2.4.1 §7.4 («كل صفحة لها تخطيط مخصص — لا قالب مكرر لكل شيء») و§33 (فهرس الصفحات والنوافذ)

## 1. عائلات التخطيط (Layout Families)

| الرمز | العائلة | الوصف | متى تُستخدم |
|---|---|---|---|
| **LF-A** | Dashboard تنفيذي | شبكة بطاقات KPI + قائمة تنبيهات + إجراءات سريعة حسب الدور | الصفحة الرئيسية ولوحات التحليلات |
| **LF-B** | جدول بيانات متقدم | PageHeader + Toolbar كامل + WeraDataGrid + DetailFlyout | كل السجلات والقوائم |
| **LF-C** | محرر متعدد الأقسام | أقسام قابلة للطي + مراجعة قبل الحفظ (§4.4) | إنشاء/تعديل الكيانات المعقدة |
| **LF-D** | مستند | ترويسة مستند + بنود + إجماليات + شريط دورة حياة | الفواتير والسندات والجرد |
| **LF-E** | Master-Detail | قائمة + تفاصيل موسعة | كشوف الحساب وكرت الحركة |
| **LF-F** | معالج (Wizard) | خطوات مرقمة بإلغاء موثق واستئناف | الإعداد والاستيراد والجرد |
| **LF-G** | تقرير | منطقة مرشحات مستقلة + نتائج + تلخيصات + تفاصيل قابلة للفتح | التقارير والتحليلات |
| **LF-H** | إعدادات | قوائم جانبية داخلية بسيطة + نماذج قصيرة | الأجهزة والإعدادات |
| **LF-P** | POS مخصص | مواصفة POS المستقلة (POS_VISUAL_SPEC) | نقطة البيع فقط |

**قواعد عامة لكل العائلات:** TopNavBar موحد (لا Sidebar) · هوامش 24/32px · عنوان 26/700 · الأسطح المحايدة غالبة · Teal للإجراء الأساسي الواحد · الذهبي للقيم المالية المميزة فقط · كل صفحة تحدد إجراءها الأساسي الواحد في Header.

## 3. نوافذ الإجراءات (ليست صفحات)
`نافذة الوزن` · `نافذة الدفع` (POS_VISUAL_SPEC §3–4) · `Print Job Details/Retry/Reprint` · `Thermal Preview 58/80` · `A4 Detailed Preview` (بطلب صريح فقط — لا يظهر خياراً افتراضياً في أي تدفق §29.11) · نوافذ الموافقة الثنائية (مشرف/مدير بكلمة مرور + سبب).

## 4. قاعدة توزيع الصفحات على الشاشة
- 1280×720: هامش 24 · جدول 6–7 أعمدة ظاهرة والبقية في Column Chooser.
- 1920×1080: هامش 32 · LF-E يوزع 40/60 · LF-G مرشحات يمين (RTL) بعمود 280px.
- كل صفحة تعلن إجراءها الأساسي الواحد (زر Teal) في PageHeader أو Toolbar — لا أزرار أساسية متعددة.
