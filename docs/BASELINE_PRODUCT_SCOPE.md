# BASELINE PRODUCT SCOPE — نطاق المنتج الأساسي المعتمد

## 1. رؤية المنتج

**WERA PRO HD** نظام تشغيل تجاري مترابط (Retail Operations Workbench) لتجارة التجزئة والبيع بالوزن — وليس تجميعة صفحات إدخال. ينجز صاحب المتجر والكاشير والمشرف والمحاسب ومندوب المخزن أعمالهم اليومية بأقل أخطاء وبمسار مفهوم من البداية إلى الإتمام، بدقة مالية ومخزنية عالية.

**الهوية:** حديثة، راقية، دقيقة، هادئة، عالية الوضوح، مناسبة لساعات استخدام طويلة. عربية أولًا بـ RTL كامل، مع دعم إنجليزي LTR فعلي عند التبديل.

## 3. نطاق المجالات (Domains) — داخل النطاق

1. **الكتالوج:** منتج/SKU/وحدات وعبوات وتحويلات/باركود وPLU/قوائم أسعار/عروض — فصل صريح لهوية المنتج عن صيغة البيع.
2. **المنتجات الوزنية:** بيع بالوزن الحي واليدوي والمبلغ المستهدف والملصق الموزون والعبوة المجهزة، بمصادر وزن موسومة.
3. **مكتبة الصور والوسائط:** أصل عالي الدقة + مصغرات + كشف تكرار + استيراد دفعات قابل للاستئناف.
4. **المخزون:** دفتر حركات موثق (الرصيد نتيجة حركات)، جرد وتسويات، تحويلات، نواقص، دفعات/صلاحية/سيريال عند التفعيل.
5. **المشتريات والموردون:** أوامر شراء حسب النطاق المعتمد، استلامات، فواتير موردين ومدفوعات، مرتجعات موردين.
6. **العملاء والذمم:** سجلات، كشوف حساب، سندات قبض/دفع، ائتمان وفق سياسة معتمدة.
7. **نقطة البيع POS:** نافذة مستقلة بلا تنقل إداري ولا شبكة منتجات، سلة مركزية، أدوات كاشير كاملة، اختصارات F1–F12.
8. **الورديات والخزينة:** فتح/إغلاق بتسوية، درج نقد بحالة موثوقة، خزائن وسندات، رأس مال بأرصدة افتتاحية معتمدة.
9. **المصروفات:** فئات قابلة للتهيئة، اعتماد، أثر مالي واحد.
10. **المحاسبة:** دفتر قيد مزدوج + دليل حسابات + فترات مالية (نطاق المحاسبة الكاملة قرار D-12).
11. **المدفوعات:** نقدي/بطاقة/مختلط/آجل بحالات موثقة، بطاقات عبر مزود حقيقي فقط.
12. **التقارير والتحليلات:** لوحة تنفيذية HOME-01 + Sales Intelligence + تقارير كاشير/ورديات/ربحية/راكد/جودة بيانات بقاموس مؤشرات موحد.
13. **الأجهزة:** قارئ باركود، ميزان، طابعة إيصال 58/80mm، طابعة ملصقات، درج نقد، طرف دفع — عبر عقود typed.
14. **المستخدمون والصلاحيات وسجل التدقيق.**
15. **النسخ الاحتياطي والاستعادة وإدارة التشغيل.**

## 5. البيئة التقنية المستهدفة

- **محطات البيع:** Windows 10/11 (إصدارات مدعومة تُثبت فعلًا عند G0 verification وG3 build) — تطبيق WinUI 3 أصلي.
- **الخادم:** ASP.NET Core 10 على .NET 10 LTS خلف HTTPS/TLS — PostgreSQL قاعدة الإنتاج المركزية.
- **خط الأساس المرجعي (بتاريخ 2026-11-01، يُعاد فحصه عند كل بوابة):** .NET 10.0.14 (Active حتى 2028-11-14) · Windows App SDK 2.6.4 Stable.
- **وضع التشغيل الافتراضي:** Online-first متعدد المحطات عبر API موثقة؛ لا اتصال مباشر من محطات الكاشير إلى PostgreSQL.

## 6. غير الأهداف في G0 (ممنوع تنفيذها في هذه المرحلة)

- لا صفحات إنتاج أو نماذج WinUI (تبدأ فعليًا في G2/G3).
- لا ترحيلات قاعدة بيانات أو مخطط نهائي (G1).
- لا عمليات مالية أو مخزنية أو بيع (G4 فما بعد).
- لا ادعاء اتصال أجهزة (كلها `NOT_CONFIGURED` حتى G10 والاختبار الفعلي).
- لا بيانات تجريبية في أي واجهة إنتاج؛ البيانات الاصطناعية مسموحة فقط في بيئة اختبار موسومة.

## 7. خارج نطاق المنتج (يُعاد التأكيد من الوثيقة الأم)

- Microservices قبل حاجة مثبتة ومبرر تشغيلي — المعمارية Modular Monolith.
- البيع Offline متعدد الأجهزة — قرار D-08، الافتراضي: غير مدعوم.
- دفع أو ضرائب إلكترونية بلا اختصاص وتكامل معتمدين (D-01، D-02).
- ترقيع نسخ قديمة — المشروع Greenfield في مستودع مستقل، والنسخ القديمة (إن وجدت) مرجع فهم فقط لا قاعدة كود.
