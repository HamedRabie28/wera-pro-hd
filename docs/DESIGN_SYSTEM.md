> **الوثيقة:** WERA-DS-001 · **الإصدار:** 1.0 (G2 — للاعتماد) · **التاريخ:** 2026-11-01
> **المرجع الناظم:** GFM-CSharp 2.4.1 §6/§7 (نظام التصميم والواجهات) و§22 (بوابة G2) — المعتمد بأمر المالك.

## 1. اتجاه التصميم الواحد — «Premium Operations, Calm Surfaces»

اتجاه بصري واحد لكل المنتج (Shell الإداري + POS + قوالب الطباعة الحرارية والمرجع البصري A4):

- **Premium Navy أساس** — هوية مؤسسية هادئة واثقة؛ الأسطح المحايدة هي الغالبة دائماً.
- **Deep Teal للإجراء الإيجابي/النشط فقط** — زر الدفع، الإيداع، الحفظ، الإضافة؛ لا يُستخدم تلويناً شاملاً.
- **Champagne Gold تمييز محدود** — شارات القيم المالية الرئيسية، علامات Premium، حدود دقيقة؛ لا يغطي الأزرار والجداول كلها.
- **لا Neon، لا تدرجات ضخمة، لا خلفيات بيضاء ساطعة تجهد العين، لا ظل ثقيل حول كل عنصر.**
- **كثافة معلومات محترمة مع تنفس:** بيانات كثيرة بلا ازدحام — شبكة 8pt صارمة.
- **اللون وحده لا يحمل حالة أبداً** — دائماً لون + نص/أيقونة/شكل (§6).
- **RTL أولوية أولى:** العربية RTL كاملة مع LTR للأكواد/الباركود/التواريخ الرقمية عند الحاجة؛ كل تخطيط يُصمم RTL أولاً ثم يُفحص LTR.

### مبادئ الحكم على أي شاشة
1. هل الأسطح المحايدة غالبة واللون وظيفي؟
2. هل الإجراء الأساسي واحد وواضح بلون Teal؟
3. هل القيمة المالية الرئيسية بارزة (26–34px) وبتباين كافٍ؟
4. هل كل حالة (تحميل/فارغ/خطأ/معطل/نجاح) مصممة لا مرتجلة؟
5. هل تعمل الشبكة 8pt وأنصاف الأقطار الموحدة دون استثناء بلا سبب؟

## 3. الشبكة والمسافات والمحاذاة

- **شبكة 8pt** ومضاعفات 4pt للعناصر الدقيقة: `4 / 8 / 12 / 16 / 24 / 32 / 40`.
- هوامش الصفحة: 24px (شاشات ≤1366px) و32px (أكبر)؛ فراغ بين البطاقات 16px؛ داخل البطاقة 16–24px.
- محاذاة: النص العربي يمين، الأرقام/العملات/الكميات **محاذاة موحدة بعرض رقمي ثابت (tabular figures)**، الأكواد والباركود LTR بخط monospace.
- لا تُخلط العملة والوحدة داخل أرقام غير واضحة — وحدة القياس عمود مستقل أو suffix ثابت.

## 4. الخطوط وسلم الحجم

- **خط التطبيق على Windows:** `Segoe UI Variable` (Display للعناوين، Text للنص) مع fallback عربي موثوق ومرخص (Segoe UI يغطي العربية على Windows 10/11). **لا يُضمَّن أي خط دون مراجعة ترخيص (§7).**
- **خطوط وثائق العلامة والتقارير الداخلية للفريق (غير التطبيق):** Cairo (عناوين) وTajawal (نص) — مرخصة ومدمجة في تقارير البوابات فقط.
- **خط الأكواد/الباركود:** `Cascadia Mono` (متوفر مع Windows) أو Consolas.

| المستوى | الحجم | الوزن | ملاحظة |
|---|---|---|---|
| عنوان الصفحة | 24–28px | Bold (700) | Cairo-like feel عبر Segoe Semibold |
| عنوان فرعي/قسم | 17–20px | Semibold (600) | |
| نص معتاد | 14–15px | Regular (400) | الحد الأدنى للنص الأساسي 14px |
| تفاصيل ثانوية | 12–13px | Regular | مساعد فقط، لا يُستعمل لنص أساسي |
| **القيمة المالية الرئيسية في POS** | **26–34px** | Bold | بتباين عالٍ ووحدة EGP منفصلة |

## 6. الأيقونات والتركيز والحركة

- أيقونات: Fluent Icons — 16px (سطر جدول)، 20px (أزرار)، 24px (تنقل). دائماً مع تسمية نصية للإجراءات المفصلية.
- التركيز: حلقة تركيز واضحة 2px بلون `action.teal` (FocusVisual) — لا يُزال التركيز البصري لأجل الجماليات؛ مطلوب لاختبار الوصول بالكيبورد.
- الحركة: مدد قصيرة `120–180ms` (Standard) و`100ms` (Fast)؛ احترام `reduce motion`؛ **لا حركة تمنع إدخال الباركود أو تُبطئ الكاشير** — انتقالات POS شبه معدومة.
- حالات المكونات الإلزامية (§7.2): `default / hover / focused / pressed / selected / disabled / loading / empty / success / warning / error`.

## 7. WERA PRO Premium Data Grid (ملخص — التفصيل في COMPONENT_CATALOG)

- ترويسة ثابتة بلون سطح ثانوي وخط متوسط الوزن؛ صف 46–52 DIP (Compact 38–42).
- حدود أفقية رقيقة فقط — لا خطوط رأسية ثقيلة ولا Zebra صارخ.
- أنواع خلايا معيارية: Text · Secondary · Numeric · Currency (EGP) · Quantity/Weight · Date/Time · Status Badge · Thumbnail 32–40 · SKU/Barcode (LTR mono) · Row Actions (الأكثر استخداماً ظاهراً والبقية في More).
- Toolbar لكل جدول: عنوان + عدد سجلات + بحث حقيقي (Debounce) + فلاتر نشطة قابلة للإزالة + فرز + تحديث + Column Chooser + Pagination + Export (بصلاحية) + إجراء رئيسي واحد.
- السلوك: server-side paging/sorting/filtering، Virtualization، skeleton للتحميل، Empty يشرح ويقدم Clear Filters، Error مع Retry لا يتحول لجدول فارغ.

## 8. نظام التنقل العلوي (§7.3 — لا Sidebar)

شريط علوي موحد لكل الصفحات الإدارية بلون `brand.navy`:
`شعار WERA PRO HD` · `الفرع/المحطة الحالية` · مجموعات قوائم قليلة (التشغيل · المبيعات · الكتالوج · المخزون · المشتريات · الأطراف · المالية · التقارير · الأجهزة · الإدارة والأمان) · `Ctrl+K بحث عام/Command Palette` · `حالة اتصال حقيقية` · `إشعارات` · `المستخدم/الدور + اللغة + الثيم`.
قائمة «المزيد» عند ضيق العرض بدل قص العناصر؛ القوائم تدعم Escape/النقر خارجها/الأسهم/Enter؛ لا وصول لصفحة محظورة عبر أمر مباشر.

## 9. تطبيق قرارات المالك على التصميم (حسم 2026-11-01)

- **D-01 (أ):** كل الأسعار المعروضة في POS والقوالب **شاملة الضريبة**؛ سطر الفصل يظهر في الإيصال («الضريبة المضمّنة 14%») وعند الترحيل. لا يُعرض أي سعر + ضريبة تُضاف عند الدفع.
- **D-07 (أ):** نافذة الوزن: دقة 1g، خطوة أزرار الوزن السريع 5g، إدخال «مبلغ مستهدف» يحسب الوزن لأقرب خطوة (200 EGP/kg × 70 EGP = 350g)، تقريب المبلغ Banker's لأقرب قرش؛ تُعرض القيمة الدقيقة والمعروضة معاً.
- **D-16 (أ):** قوالب فاتورة المشتريات الداخلية 58/80 المستقلة جاهزة للطباعة التلقائية بعد الاعتماد/الترحيل على طابعة المالية؛ وسم REPRINT واضح على كل نسخة معاد طباعتها.
