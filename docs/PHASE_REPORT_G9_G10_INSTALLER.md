## 4. حزمة التثبيت الاحترافية (`installer/`)

| البند | القيمة |
|---|---|
| التقنية | Inno Setup 6.3+ — معالج **عربي RTL كامل** (`RightToLeft=yes` + تعريب رسائل شامل عبر `[Messages]`/`[CustomMessages]`) |
| العزل | .NET 10 Self-Contained + Windows App SDK Self-Contained — **صفر متطلبات مسبقة على جهاز العميل** |
| التوافق | Windows 10 (1809/بناء 17763 فأحدث) · Windows 11 · x64 (شامل أجهزة ARM64 بالمحاكاة) · حزمة ARM64 أصلية اختيارية |
| فحص ما قبل التثبيت | `InitializeSetup` يتحقق من بناء ويندوز ويعرض رسالة عربية تعليمية عند القِدم — بديل الفشل الصامت |
| الضغط | `lzma2/max` + `SolidCompression` + `InternalCompressLevel=ultra64` |
| الترقية | `AppId` ثابت (5D944405-EC34-4CD3-97B7-2CD9A6F23638) → إغلاق آمن للتطبيق (`CloseApplications`) → استبدال → إعادة فتح (`RestartApplications`) |
| التثبيت الصامت | `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` · `/ALLUSERS`/`/CURRENTUSER` · `/DIR` · `/TYPE` · `/LOG` · رمز خروج 0 = نجاح |
| VC++ Redist | مكون اختياري يُثبَّت صامتًا **فقط عند غيابه** (فحص بصمة سجل `HKLM\...\VC\Runtimes\x64` الرسمية) |
| الإزالة | Uninstaller قياسي (إعدادات ويندوز) + اختصار إزالة في قائمة ابدأ + نظافة كاملة لمجلد التثبيت — بيانات المستخدم تبقى عمدًا |
| البناء | `build-installer.ps1`: نشر + تنزيل VcRedist + تحقق إصدار Inno (يرفض <6.3) + SHA256 — سطر واحد |

**حد التوافق المعماري الموثق:** ويندوز قبل 1809 (و7/8/8.1) لا يشغّل WinUI 3 بقرار مايكروسوفت نفسها — أي أن كل ويندوز لاحق لأكتوبر 2018 وكل ويندوز 11 مدعوم؛ وهو عمليًا «كل الإصدارات المدعومة فعلًا للتطبيق»، والحزمة تخاطب غير المدعوم برسالة عربية صريحة بدل الفشل الغامض.

## 5. الهوية البصرية الخارجية المتقدمة

- **المولّد:** `scripts/make_icons.py` (حتمي قابل لإعادة التشغيل) — الأصول: `src/WeraPro.Desktop/Assets/` (19 ملفًا: ICO متعدد المقاسات 16→256 + PNG 16→512 + شعارات MSIX مستقبلية) و`installer/Assets/` (setup.ico + بانر معالج 164×314 + شعار 55×58) و`docs/assets/appicon_1024.png`.
- **التصميم:** حرف W هندسي أبيض بظل عميق فوق تدرج قطري كحلي `#102238`→تركوازي `#0D8379` مع توهج علوي وحافة داخلية رفيعة، وخط سفلي ذهبي `#B9955C` — كل القيم من `DesignTokens.xaml` المعتمدة G2 (تناسق كامل مع واجهة الدخول: بطاقة W نفسها).
- **التضمين:** `<ApplicationIcon>` في csproj (أيقونة exe/شريط المهام/عنوان النافذة — هوية واحدة متوارثة لا صور مشتتة) + `IconFilename` للاختصارات + هوية المثبِّت (بانر/شعار/أيقونة الحزمة).
- **ضد الضبابية:** `PerMonitorV2` في الـmanifest + توليد supersampled للقيسات الصغيرة.

## 6. خط أنابيب CI (`.github/workflows/build-installer.yml`)

على `windows-latest`: نشر معزول → تثبيت Inno Setup عبر winget → تنزيل VC++ Redist الرسمي → ترجمة ISCC → تحقق + SHA256 → **Artifact دائم** + **GitHub Release تلقائي عند وسم `v\*`**. يعالج قيد B-05: بناء الحزمة النهائية دون حاجة لبيئة ويندوز محلية.

## 8. المتبقي (بأولوية)

1. **أول بيئة ويندوز:** `powershell -File installer\build-installer.ps1` → `WeraProSetup-0.3.0-win-x64.exe` → تثبيت على Win10 وWin11 → لقطات الالتزام G2..G8 (+G9 التقارير/HOME-01) — البند المؤجل أصلاً بشرط B-05.
2. اختبار العتاد الفعلي (G10/B-07) عند توفر الأجهزة: قارئ/طابعة 58+80mm/ملصقات/ميزان/درج/طرف دفع.
3. حزمة ARM64 أصلية عند الحاجة: `build-installer.ps1 -Platform arm64`.
4. ربط `Api:BaseUrl` النهائي قبل التغليف الإنتاجي حسب طوبولوجيا النشر (محلي `http://localhost:5400/` افتراضيًا أو خادم شبكة).
5. استكمال بقية بوابات G14 (GO/NO-GO) بعد G11–G13 وفق الخريطة.
