# PRINT MEDIA POLICY — 58mm / 80mm / A4 Detailed Only
> **سياسة الطباعة الحرارية المتوسطة والصغيرة، مع A4 للتفاصيل الكاملة فقط**
> **الوثيقة:** WERA-PR-001 · **الإصدار:** 1.0 · **التاريخ:** 2026-11-01 · **المرجع الناظم:** GFM-CSharp 2.4.1 (مسودة مقترحة) §29.1–29.2 · **الملحق المصدر:** «سياسة الطباعة الحرارية المتوسطة والصغيرة، مع A4 للتفاصيل الكاملة فقط»

---

## 1. القرار النهائي للمقاسات (ملزم)
- **المتوسط:** رول حراري **80mm** — القالب `ROLL_MEDIUM_80`.
- **الصغير:** رول حراري **58mm** — القالب `ROLL_SMALL_58`.
- **A4:** وضع تفصيلي اختياري **فقط** — القالب `A4_DETAILED_FULL`؛ لا يُستخدم إلا عند طلب كشف كامل أو دقيق أو مستند متعدد الصفحات، وبإجراء صريح من مستخدم مخوّل.

**ممنوعات قاطعة:**
- ممنوع اختيار A4 تلقائياً.
- ممنوع التحويل إليه عند ازدحام محتوى الإيصال أو فشل طابعة 58/80mm.
- لا يُعتمد A5 خياراً افتراضياً لهذه المجموعة.
- لا تُضاف مقاسات أخرى إلا بطلب واعتماد منفصل واختبار فعلي.
- لا يتحول فشل 80mm إلى 58mm أو A4 تلقائياً، ولا العكس.

## 2. فلسفة الطباعة
جميع مستندات WERA PRO HD اليومية مصممة أساساً للطباعة الحرارية المتوسطة أو الصغيرة. المعايرة والإعدادات تُجرى مرة واحدة لكل طابعة/محطة/مستند؛ وبعد نجاح الإعداد:
- يختار النظام قالب 80mm أو 58mm تلقائياً من ملف الطابعة المعتمد (Printer Profile).
- يرسل المهمة إلى الطابعة المحددة لهذا النوع من المستندات.
- لا يعرض Print Dialog في التدفق التشغيلي العادي.
- لا يفتح A4 من تلقاء نفسه.
- لا يغير عرض المستند أو يمدده ليلائم طابعة أخرى.
- لا يخلط مستندين مختلفين في مهمة واحدة دون Batch Print صريح.

## 3. فصل اسم الوسيط عن عرض الطباعة (قيم مستقلة ملزمة)
| القيمة | المعنى |
|---|---|
| `MediaWidthMm` | العرض الاسمي للورق |
| `PrintableWidthMm` | العرض القابل للطباعة بعد مناطق عدم الطباعة — **أساس قياس المحتوى** |
| `DpiX` / `DpiY` | دقة الطابعة/التعريف الفعلية |
| `LeftMarginMm` / `RightMarginMm` | هوامش عدم الطباعة |
| `VerifiedMediaWidthMm` | المقاس المتحقق منه بالاختبار الفعلي |
| `PrinterProfileVersion` | نسخة ملف إعداد الطابعة |

لا يُستخدم اسم الطابعة التجاري وحده لتحديد المقاس؛ فقد يعمل الموديل الواحد مع أكثر من درج أو تعريف أو عرض ورق.

## 4. الطول الديناميكي — بلا قص ولا انتقال صامت إلى A4
- ارتفاع المستند دالة المحتوى الفعلي (أصناف، أسماء طويلة، SKU/باركود، كميات وأوزان، خصومات وضرائب، وسائل دفع، مرفقات، عدد حركات/بنود).
- Layout Engine يحسب الارتفاع قبل إرسال المهمة، مع مساحة تغذية/قص مناسبة للطراز المختبر.
- المستند الطويل ضمن قدرة الطابعة: رول متصل بارتفاع محسوب — لا تصغير خط يضر القراءة، لا قص للإجمالي/التذييل.
- تجاوز حدود الطابعة: لا تحويل تلقائي إلى A4؛ تُعرض خيارات صريحة (تقسيم الرول إلى أجزاء مرقمة إن دُعم، أو طلب نسخة A4 تفصيلية)، ولا حذف سطر إلزامي دون تسمية المستند «ملخصاً» بوضوح.

## 5. منع التشوه والخلط (ملخص)
1. لا تطبع صورة PNG ممدودة باعتبارها مستنداً حقيقياً؛ القوالب الإنتاجية ديناميكية من بيانات محفوظة.
2. لا `Fit to Page` ولا `Shrink to Fit` ولا أي Scale غير معتمد.
3. لا يجعل قالب 80mm نسخة مكبرة من 58mm أو العكس — قالب مستقل لكل وسيط.
4. لا خلط ترتيب الحقول أو نوع المستند بين فاتورة وكشف وسند ومطالبة.
5. لا قص اسم منتج أو كود أو مبلغ أو رقم مستند.
6. حروف سوداء واضحة على خلفية بيضاء وفواصل محايدة؛ لا تباين منخفض ولا خلفيات داكنة كثيفة.
7. حفظ تشكيل العربية واتصال الحروف وRTL، مع LTR للأكواد والتواريخ والأرقام عند الحاجة.
8. لا جدول عريض غير مناسب لـ58mm — كتل أصناف متعددة الأسطر بدلاً منه.
9. ملخص الإجمالي/المدفوع/المتبقي بارز بلا لبس؛ ووسم «ملخص» على كل إيصال لا يسرد التفاصيل الكاملة.

## 6. القرارات المعلقة على صاحب المنتج
- **D-15** جرد الطابعات الفعلية وتعيين الأدوار (حتى الجرد: كل الطابعات `NOT_CONFIGURED` ويوقف التوجيه — لا تخمين).
- **D-16** سياسة الطباعة التلقائية حسب نوع المستند (اعتماد/تعديل الجدول المقترح في GFM 2.4.1 §29.10).
- **D-17** تعيين الطابعة المؤمنة (Confidential) لمستندات الرواتب.
- **D-18** طابعة A4 المعتمدة لفئة A4 Detailed Reports وصلاحية «طباعة تفصيلية كاملة A4».
