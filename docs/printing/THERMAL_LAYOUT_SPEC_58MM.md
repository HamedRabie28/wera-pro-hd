# THERMAL LAYOUT SPEC — 58mm (Small)
> **الوثيقة:** WERA-PR-003 · **الإصدار:** 1.0 · **التاريخ:** 2026-11-01 · **المرجع الناظم:** GFM-CSharp 2.4.1 §29.2.2 و§29.5.3 و§29.6 · **القالب:** `ROLL_SMALL_58`

## 1. مبادئ التصميم المستقل
- يُصمَّم كل مستند لقالب 58mm **خصيصاً**؛ ممنوع تصغير صورة أو قالب 80mm آلياً ليصبح 58mm.
- تخطيط رأسي/متراكب للحقول عند ضيق العرض — لا جداول متعددة الأعمدة مزدحمة.
- تبقى الأسعار والأوزان والأكواد والإجماليات واضحة ومقروءة دائماً.

## 2. ترتيب عرض صنف (قاعدة إلزامية)
لا تُضغط المنتج والكمية والسعر والإجمالي في صف واحد إذا أدى ذلك إلى الالتباس. الترتيب:
1. اسم المنتج.
2. SKU أو المرجع.
3. الكمية/الوزن.
4. سعر الوحدة.
5. الإجمالي.
ويمكن وضع الخصم كسطر فرعي أسفل الصنف.

## 3. الإجمالي
- يُعرض الإجمالي النهائي في مساحة بارزة عالية التباين.
- ملخص الإجمالي/المدفوع/المتبقي مميز دون لبس (PRINT_MEDIA_POLICY §5 ق9).

## 4. الخط
- لا يجعل حجم الخط أصغر من الحد المقروء الذي تم اختباره على الطابعة (يُثبَّت بالمعايرة الفعلية في G10 — قرار D-15).
- لا يُصغَّر الخط تلقائياً لإجبار كشف طويل على عرض ثابت.

## 5. منع التشوه الخاص بالـ58mm
- لا جدول عريض غير مناسب للعرض؛ تُستخدم كتل أصناف متعددة الأسطر.
- لا قص اسم منتج أو كود أو مبلغ أو رقم مستند؛ التفاف النص الطويل بدل القص.
- وسم «ملخص» بوضوح على كل إيصال لا يسرد التفاصيل الكاملة، وأتح وضع التفصيل الكامل منفصلاً.

## 6. الطول الديناميكي
- ارتفاع المستند محسوب من المحتوى الفعلي عبر Layout Engine قبل إرسال المهمة.
- المستند الطويل ضمن قدرة الطابعة: رول متصل — بلا قص للإجمالي/التذييل.
- تجاوز الحدود: تُعرض خيارات صريحة (أجزاء مرقمة إن دُعم / طلب نسخة A4 تفصيلية) — لا تحويل تلقائي.

## 7. العرض الفعلي
- القياس على `PrintableWidthMm` المعايَر، لا على العرض الاسمي 58mm.
- تُسجَّل القيم في Printer Profile: `MediaWidthMm`، `PrintableWidthMm`، `VerifiedMediaWidthMm`، `DpiX/DpiY`، الهوامش، `PrinterProfileVersion`.

## 8. العربية والاتجاه
- تشكيل عربي سليم واتصال حروف صحيح وRTL كامل؛ مع LTR للأكواد والتواريخ والأرقام عند الحاجة.
- اختبار إلزامي للحقول المختلطة عربي/لاتيني على الطابعة الفعلية قبل اعتماد الملف.
