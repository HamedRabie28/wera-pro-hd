# hardware_evidence/ — أدلة الطابعات الفعلية
**الحالة:** فارغة عمداً في G0 — الأجهزة غير مجرودة بعد (المانع B-07 / القرار D-15).

## ما يُوضع هنا (من G10 عند توفر الأجهزة)
- صورة اختبار حقيقية لكل طابعة (Test Receipt موسوم بوضوح).
- نتيجة الطابعة والموديل وDriver وإصدار Printer Profile (اختبار 25 في PRINT_TEST_MATRIX.md).
- سجل المعايرة: القيم الفعلية لـMediaWidthMm وPrintableWidthMm وVerifiedMediaWidthMm وDPI والهوامش.

## قواعد
- «عند توفرها» — غياب الجهاز يوسم `BLOCKED_EXTERNAL_DEPENDENCY`، ولا يُسمح بمحاكاة تدعي الاتصال.
- لا تُخترع موديلات أو طرازات؛ تُعبأ القيم من الجرد الفعلي بعد اعتماد D-15.
- تقبل Windows Spooler ليس تأكيداً لخروج الورقة مادياً إذا كان التعريف لا يوفر هذا التأكيد.
