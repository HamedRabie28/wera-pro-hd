# A4 DETAILED FULL SPEC — وضع التفصيل الكامل فقط
> **الوثيقة:** WERA-PR-005 · **الإصدار:** 1.0 · **التاريخ:** 2026-11-01 · **المرجع الناظم:** GFM-CSharp 2.4.1 §29.2.3 و§29.11

## 1. التعريف
- المقاس الفيزيائي: 210 × 297mm — القالب `A4_DETAILED_FULL`.
- **وضع تفصيلي اختياري فقط**: لا يظهر خياراً افتراضياً في POS أو صفحات المستندات اليومية.
- لا يُختار تلقائياً بسبب عدد الأصناف أو طول النص أو عدم توافر رول حراري.

## 2. شرط الفتح
- يُفتح **فقط** بإجراء صريح مثل «طباعة تفصيلية كاملة A4» أو «تصدير/طباعة كشف كامل».
- من مستخدم مخوّل (صلاحية مناسبة)، مع معاينة عند الحاجة.
- على طابعة A4 معينة لها دور `A4 Detailed Reports` في Printer Profile (قرار D-18).

## 3. مستوى التفصيل — ليس قالباً حرارياً مكبراً
A4 يختلف **من حيث مستوى التفصيل** لا بحجم الخط:
- تقرير مفصل منظَّم متعدد الصفحات عند الحاجة.
- تُكرَّر رؤوس الجداول عبر الصفحات عند الحاجة.
- تظل نسخة الرول سليمة كاملة بمحتواها؛ لا يغيّر طلب A4 القالب الأصلي للمستند، ولا تنشأ نسخة مالية جديدة بطلبه.
- مطابقة A4 التفصيلي في ميزان المراجعة والتقارير الشهرية الكاملة تُطابق مصادرها (اختبار إلزامي).

## 4. نطاقات الاستخدام المعتمدة
- التقارير الشهرية الكاملة.
- كشوف جميع الفواتير (مثل ملحق مبيعات الكاشير بكل فاتورة).
- كشوف الحساب الطويلة (كشف حساب المورد بكامل الحركات وأعمار الديون).
- الملاحق الدقيقة متعددة الصفحات (مطابقة PO/Receipt/Invoice الكاملة).
- ملفات المراجعة الإدارية (ميزان المراجعة وما في حكمه من التقارير المالية الكاملة).

## 5. لكل نوع مستند (مطابقة لمصفوفة القوالب)
| النوع | ما يضيفه A4 التفصيلي |
|---|---|
| فاتورة العميل | نسخة تفصيلية عند طلبها فقط |
| فاتورة مشتريات داخلية | كامل صفوف مطابقة PO/Receipt/Invoice والفروقات والمرفقات والموافقات |
| كشف حساب المورد | كل الحركات والتخصيصات والدفعات غير المخصصة وأعمار الديون الكاملة |
| سند دفع المورد | كل تخصيصات الدفعة والمرفقات والمراجعات والموافقات |
| كشف الراتب | كشف كامل وتفاصيل الحضور والمبيعات (كل فواتير الكاشير ببياناتها) |
| ملحق مبيعات الكاشير | جميع فواتير الشهر وصفوف المبيعات؛ ومجموع التفاصيل يطابق ملخص الشهر |
| ملحق الحضور والورديات | السجل الكامل للأحداث والتصحيحات ومصدر الوقت ومن اعتمده |
| سند سداد الراتب | تفاصيل دفعات/مراجع متعددة |
| سند مصروف تشغيلي | البنود والمرفقات والموافقات كاملة |
| مطالبة مصروف موظف | كل البنود والمرفقات والمراجعات |
| سند تعويض/سداد مصروف | تفاصيل تسوية كاملة |
| تقرير رقابة مصروفات الكاشير | كل الحركات حسب الموظف والوردية والمصدر |

## 6. ممنوعات
- لا يظهر A4 خياراً افتراضياً في أي تدفق طباعة يومي.
- لا تحويل تلقائي إليه عند ازدحام المحتوى أو فشل طابعة 58/80mm.
- لا يُستخدم «تكبير قالب رول» بديلاً عن تصميم A4 تفصيلي مستقل.
- معاينة PDF/A4 منفصلة عن الطباعة الحرارية ولا تغيّر القالب الأصلي (اختبار 22).
