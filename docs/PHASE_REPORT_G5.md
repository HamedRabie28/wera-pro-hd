## 1. الملخص — ما اكتمل وما لم يكتمل

**اكتمل (وبُني واختُبر فعلياً — لا ادعاء):**

- **رفع فردي كامل التحقق (§6.1):** `POST /api/v1/media` — متطفل ترويسات يقرأ النوع والأبعاد من PNG IHDR / JPEG SOF **قبل أي فك ترميز** (قراءة واحدة ≤64KB — لا تحميل الملف في الذاكرة)، ورفض صريح برموز مسماة: `UNSUPPORTED_MEDIA_TYPE` (JPEG/PNG فقط)، `FILE_TOO_LARGE` (>10MB)، `DIMENSIONS_EXCEED_LIMIT` (قنبلة الفك >24MP تُرفض من الترويسة قبل الترميز)، `CORRUPT_IMAGE` (**فحص بنية كامل يطارد البتر حتى IEND/EOI بتخطي متدفّق** — ملف PNG مبتور بعد آخر قطعة أو JPEG بلا EOI يُرفض حتى لو فكه المفك جزئياً).
- **تخزين موجَّه بالمحتوى بلا مسارات عميلة:** مفاتيح `media/{h2}/{sha256}/orig|thumb-catalog|thumb-pos|preview` — `client_name` للعرض فقط ولا يصل نظام الملفات أبداً؛ حارس `IsManagedKey` يرفض أي اجتياز مسار (`..`/فاصل ويندوز/فراغ/مقاطع غير سداسية) بالمفتاح نفسه.
- **التطابق التام والاكتشاف (§6.1/§6.2):** SHA-256 متدفقة (64KB Buffer) — **المطابق تماماً يُرفض 409 مع الإشارة الكاملة للأصل القائم** (يُربط الموجود ولا يُنشأ ثانٍ: اختبار مخصص يثبت صفر صفوف جديدة)؛ وبصمة إدراكية **aHash 64-bit** (متوسط 8×8 رمادياً) لكل أصل + استخراج أزواج «المشتبه بصرياً» (هامنغ ≤8) بتجميع دلو لكل بايت **تجنيب O(n²)** — **تقرير فقط، لا دمج ولا حذف تلقائي** (§6.2).
- **ثلاث نسخ مستقلة (تصغير فقط — لا تكبير أبداً والأصل لا يُستبدل §6.1):** thumb-catalog 320 / thumb-pos 128 / preview 1024 — تُطلب بنسخة منفصلة لكل سياق (شبكة المكتبة/POS/المعاينة)، وخدمة المحتوى تضع **ETag من البصمة + Cache-Control** لكل نسخة.
- **الربط وفك الربط والرئيسية (§6.3):** ربط بهدف واحد (منتج **أو** صيغة بيع — الاثنان معاً `ONE_TARGET_ONLY` 400)، **لا ربط مزدوج** (فهرسان فريدان جزئيان V016 + 409 `LINK_ALREADY_EXISTS`)، فك الربط لا يمس الأصل إطلاقاً، وتعيين رئيسية يخلي باقي روابط الهدف تلقائياً (قيد `uq_product_images_primary_sku` من V002 + T-MED-15). **اختبار 0/1/عدة صور مخصص** يثبت كل مسار.
- **أولوية الصورة الافتراضية للصيغة (§6.3 «أولوية واضحة»):** قاعدة مجال نقية `DefaultImagePriority`: رئيسية الصيغة ← أول صورة صيغة (sort ثم link_id) ← رئيسية المنتج ← أول صورة منتج ← Placeholder؛ معروضة عبر `GET /api/v1/catalog/skus/{id}/default-image` لتغذية POS والكتالوج في G7.
- **الحذف محمي بمراجعة (§6.1):** `DELETE /api/v1/media/{id}` يُرفض **409 حاملاً قائمة الروابط كاملة** (`references`) ما دام الأصل مربوطاً — «المراجعة» هي هذه القائمة؛ بعد فك الروابط كلها يُحذف وتُكنس ملفاته الأربع من المخزن (اختبار يثبت الكنس الفعلي من القرص).
- **الاستيراد الدفعي (§6.1/§6.2):** إنشاء مهمة OPEN ← ترحيل ملفات (multipart متعدد — الرفض عند الإضافة بسببه المسماة FAILED فوراً) ← تشغيل RUNNING عند **عامل خلفي حقيقي** (`MediaImportWorker` — SKIP LOCKED متعاون) ← إلغاء آمن (يتوقف عن الالتقاط الجديد ولا يلقي ملفاً قيد المعالجة) ← **استئناف يقرأ حالة كل ملف من القاعدة لا عداداً** ← تقرير لكل ملف وhistogram أخطاء. **حالة كل ملف محفوظة في القاعدة** (PENDING/PROCESSING/DONE/FAILED/SKIPPED بقيود اتساق نتيجة/حالة T-MED-03..07).
- **بصمة نطاق التخزين (`storage_scope`):** 16 سداسياً من SHA-256 لجذر المخزن — لا يعالج عاملٌ مهمةً بايتاتها خارج متناوله (جذر مختلف)، والجذور المشتركة تتعاون عبر SKIP LOCKED — مختبراً باختبار مخصص (عامل بجذر غريب يتجاهل المهمة حتى يعود النطاق).
- **تعافي الانهيار:** صف PROCESSING معلق (خادم مات أثناءه) يُعاد إدراجه PENDING بعد مهلة سماح 30 ثانية بلا لمس ملف عامل حي — اختبار مخصص (StaleProcessingHealed).
- **RBAC خادمي (§18):** ترحيل **V016**: `catalog.media.read` لكل الأدوار السبعة (المصغرات تكوين عمل — نمط V014/V015)، `catalog.media.manage` لـOWNER/MANAGER/STOREKEEPER، و`catalog.import.run` (من V009) يُمنح لـSTOREKEEPER — مختبراً: الكاشير يقرأ ولا يدير ولا يستورد (403)، المدير يدير ولا يستورد، المخازني كامل الصلاحيات، والمجهول 401 على كل نقطة.
- **الاختبار المرجعي 100,000 صورة (قيد البوابة النصي) — مكتمل فعلياً:** راجع **G5_PERFORMANCE_REPORT.md**: 100,000/100,000 DONE · 0 فشل · 0 تخطٍ · 100,000 بصمة متميزة · 100,000 مصغرة، **مع 3 إيقافات خادم متعمدة أثناء المعالجة والاستئناف من حالة كل ملف حتى الاكتمال**؛ RAM Report: الذروة 238MB مسطحة من 5k إلى 100k (معالجة متدفقة — الذاكرة لا تنمو بحجم الدفعة)؛ **«لا تعطيل POS»**: 3,793 طلباً أثناء المعالجة p50=8.6ms · p95=16.0ms · p99=25.2ms · صفر إخفاقات؛ والتخطي المتعمد للمكرر: 500/500 skipped يشيرون للأصول القائمة.
